# UK Online Retail Sales Analysis

## Project Overview

An interactive sales analysis dashboard developed using Microsoft Excel to explore the sales performance of a UK online retailer.

The project analyses 2,000 orders, examining revenue, product performance, regional sales, payment methods and monthly trends. An interactive dashboard was developed to present key performance indicators (KPIs), visualise sales patterns and identify actionable business insights.

## Project Objectives

- Analyse overall sales performance and revenue distribution.
- Identify the highest-performing regions and product categories.
- Examine customer payment method preferences.
- Identify monthly sales trends and fluctuations.
- Develop an interactive dashboard to communicate findings effectively.

## Tools & Techniques

**Microsoft Excel**

The following Excel features and techniques were used:

- Excel Tables and structured references.
- Excel formulas and functions.
- PivotTables for data summarisation and analysis.
- PivotCharts for data visualisation.
- Slicers for interactive filtering.
- KPI calculations and dashboard development.
- Business insight identification and reporting.

## Dashboard

The interactive dashboard provides an overview of sales performance through four key performance indicators:

- **Total Revenue:** £460,836
- **Total Orders:** 2,000
- **Units Sold:** 5,963
- **Average Order Value:** £230.42

Three interactive slicers allow users to filter the dashboard by region, payment method and product.

## Key Business Insights

The analysis identified several notable findings:

**1. Regional Performance**

The South East generated the highest regional revenue, totalling £84,638, highlighting its importance to the retailer's overall sales performance.

**2. Product Performance**

Electronics was the highest-performing product category, generating £243,705 in revenue. Laptops led individual product types, generating £144,900.

Interestingly, Sports recorded the highest sales volume, with 1,565 units sold, despite Electronics generating the highest category revenue.

**3. Sales Trends**

Card payments generated the highest revenue, totalling £128,267.

December recorded the highest monthly revenue at £46,039, while February recorded the lowest at £32,868. This suggests potential seasonal variation in purchasing activity.

*Note: Monthly analysis is based on data from 2025.*
